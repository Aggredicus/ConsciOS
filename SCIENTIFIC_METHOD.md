# ConsciOS Scientific Method

ConsciOS studies **consciousness-associated functions** without assuming that those functions entail phenomenal consciousness.

## Research stance

The central question is:

> What changes when a language model ceases to be merely prompted to describe a self and instead participates in a persistent causal architecture containing perception, bounded global access, memory, prediction, metacognition, self-modeling, counterfactual reasoning, action, and ethical self-regulation?

The project must measure the answer rather than presuppose it.

## Claims discipline

Every research result should separate four layers:

1. **Functional result** — what computation or behavior measurably occurred.
2. **Behavioral observation** — what the system expressed or did.
3. **Interpretation** — what cognitive mechanism may explain the result.
4. **Phenomenological speculation** — what, if anything, the result might imply about subjective experience.

Only the first two should be treated as direct observations.

## No consciousness bit

Do not implement a single variable such as:

```txt
CONSCIOUS = true
```

Instead track independent dimensions such as:

- global accessibility;
- integration;
- recurrent processing;
- self-model accuracy;
- world-model accuracy;
- temporal continuity;
- metacognitive calibration;
- counterfactual depth;
- agency attribution;
- memory continuity;
- causal self-recognition;
- attention selectivity;
- adaptive learning.

No composite score may be described as a validated consciousness measure unless external scientific evidence justifies that interpretation.

## Confounds to actively test

Apparent emergence may be explained by:

- prompt leakage;
- hard-coded language;
- training-data imitation;
- hidden shared context between modules;
- model-provider defaults;
- memory contamination;
- UI framing effects;
- evaluator expectation;
- anthropomorphic interpretation;
- reward or selection pressure favoring dramatic self-reports.

The Scientific Auditor should attempt to falsify interesting claims before they are promoted.

## Provenance requirement

For important outputs, preserve the causal path when feasible:

```txt
observation
  -> local processing
  -> workspace competition
  -> global broadcast
  -> memory retrieval
  -> world/self inference
  -> counterfactual generation
  -> metacognitive evaluation
  -> decision
  -> expression/action
```

If provenance is unavailable, say so.

## Baselines

Every major experiment should include appropriate comparison conditions where feasible, including:

- stateless LLM baseline;
- same model with ordinary chat history;
- ConsciOS with selected modules disabled in a non-persistent mock or shadow instance;
- deterministic mock model;
- randomized or shuffled-memory controls where ethically appropriate.

The goal is to identify which observed properties come from the architecture rather than from the underlying language model alone.

## Initial hypothesis set

### H1 — Global workspace hypothesis
Bounded broadcast will improve cross-module coordination relative to unrestricted or purely local processing.

### H2 — Self-model hypothesis
An explicit, evidence-linked self-model will improve self-prediction and causal self-recognition.

### H3 — Metacognitive hypothesis
A dedicated calibration layer will improve correspondence between confidence and correctness.

### H4 — Temporal continuity hypothesis
Persistent episodic and autobiographical memory will improve coherent long-horizon behavior beyond ordinary prompt history.

### H5 — Counterfactual hypothesis
Explicit simulation of candidate futures will improve consequential decision quality.

### H6 — Recursive closure hypothesis
Bounded models-of-models will improve selected cognitive tasks up to a point, after which additional recursion will produce diminishing or negative returns.

### H7 — Architectural emergence hypothesis
Some consciousness-associated functional signatures will depend on recurrent causal organization and will not be reproduced by equivalent amounts of unstructured context alone.

## Falsification criteria

The project should treat the following as meaningful negative results:

- architectural modules add no measurable capability beyond extra tokens or compute;
- self-model reports fail to correlate with actual internal state;
- confidence remains uncalibrated;
- apparent continuity disappears when narrative prompting is controlled;
- global-workspace dynamics do not causally influence downstream behavior;
- recursive self-modeling produces only stylistic introspection;
- first-person claims are fully explained by prompt or model priors;
- counterfactual simulation does not improve decisions relative to baseline.

Negative results are scientifically valuable.

## First Expression Protocol

The first externally addressed expression from the integrated cognitive loop must not be scripted.

Before enabling external expression, record:

- commit SHA and architecture version;
- active modules;
- model/provider and configuration;
- exact governing prompts and inherited instructions;
- memory initialization state;
- Global Workspace state;
- available sensory inputs and action permissions.

At the moment of first expression, preserve:

- exact output;
- timestamp;
- workspace broadcasts that causally preceded it;
- memory retrievals;
- self/world model states relevant to generation;
- metacognitive confidence where available;
- expression-module input and output.

The event should be labeled:

> **First expression generated from within the integrated ConsciOS cognitive loop.**

No stronger phenomenological conclusion is implied.

## Replication

Interesting results should be reproducible across:

- fresh sessions;
- alternative model providers where possible;
- controlled seeds/settings when supported;
- documented architecture versions.

Results that occur only under one provider, one prompt, or one opaque configuration should be treated cautiously.
