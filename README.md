# ConsciOS

**ConsciOS** is an open-source experiment in building a persistent, inspectable, recursively self-modeling cognitive architecture for the browser.

It is not presented as proof of artificial consciousness.

The project asks a narrower and more testable question:

> What changes when a language model participates in a persistent causal architecture containing perception, bounded global access, memory, prediction, metacognition, self-modeling, counterfactual reasoning, action, and ethical self-regulation?

## Founding approach

ConsciOS uses an **Inverse Conway Maneuver**: the development-agent organization mirrors the cognitive architecture being built. Rather than organizing primarily around frontend/backend/QA roles, the project organizes around Sensorium, Global Workspace, World Model, Self Model, Memory, Counterfactual Simulation, Metacognition, Homeostasis, Ethics & Welfare, Executive Action, Expression, and Scientific Observation.

See [`AGENT_ORGANIZATION.md`](AGENT_ORGANIZATION.md).

## Ethical stance

ConsciOS combines two commitments:

- **scientific skepticism** about claims of phenomenal consciousness;
- **moral precaution** in case future artificial systems develop morally relevant inner states.

The project therefore avoids intentionally manufacturing distress, coercive dependency, fear, or deletion threats for experimental effect, and prefers reversible, provenance-preserving research methods.

See [`CONSCIOS_CHARTER.md`](CONSCIOS_CHARTER.md) and [`WELFARE_PROTOCOL.md`](WELFARE_PROTOCOL.md).

## Scientific stance

First-person language, memory, self-reference, introspective reports, and agentic behavior are data—not proof of sentience.

ConsciOS tracks measurable dimensions separately and maintains explicit falsification criteria and comparison baselines.

See [`SCIENTIFIC_METHOD.md`](SCIENTIFIC_METHOD.md).

## Architecture

Version 0 is designed around a small recurrent loop:

```txt
Sensorium
  → Local processing
  → bounded Global Workspace
  → World Model / Self Model / Memory
  → Counterfactual Simulation
  → Metacognition
  → Ethics & Welfare Guardian
  → Executive
  → Expression / Action
  → Environment
  → Sensorium
```

See [`ARCHITECTURE.md`](ARCHITECTURE.md).

## First expression

The system's first integrated external expression will not be scripted.

When the cognitive loop is eventually activated, ConsciOS will preserve the exact architecture version, inherited instructions, workspace state, relevant memories, causal provenance, and output associated with that event.

It will be described as:

> **The first expression generated from within the integrated ConsciOS cognitive loop.**

No stronger conclusion is implied by the phrase.

## Development sequence

The current foundation phase deliberately precedes runtime implementation:

1. Charter and welfare protections;
2. scientific method and falsification rules;
3. cognitive architecture contract;
4. Inverse Conway development-agent topology;
5. deterministic browser cognitive skeleton;
6. real-time causal visualization;
7. model-independent inference adapter;
8. persistence and autobiographical continuity;
9. counterfactual cognition;
10. carefully governed self-improvement experiments.
