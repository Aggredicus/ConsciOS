# Development Agent Society

Each file in this directory is a role contract, not a claim that a separate conscious agent exists. The contracts constrain development context and ownership so the team organization mirrors the cognitive architecture.

Every agent contract specifies responsibility, owned paths, inputs, outputs, allowed communication, forbidden dependencies, invariants, tests, failure modes, and ethical considerations.

Agents communicate preferentially through durable typed artifacts: schemas, issues, commits, PRs, experiment records, causal traces, and interface contracts.
