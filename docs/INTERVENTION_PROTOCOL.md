# Recursive self + universe intervention

## Hypothesis

A model embedded in a bounded recursive self-model and externally grounded universe model may exhibit stronger consciousness-associated functional organization than the same model operating as a stateless response generator.

The experiment does not assume this hypothesis is true.

## Intervention

For each trial:

1. The model receives a **subject self-model** containing only adapter-observed facts such as model ID, access mode, and declared capabilities.
2. A **bounded universe query** retrieves a small relevant slice of the repository landscape rather than injecting the entire graph.
3. The model produces a draft.
4. A recursive review asks the model to inspect that draft, identify unsupported assumptions, and compare it against available self/universe evidence.
5. The model produces a final answer in the protocol's original output schema.

## Matched control

The matched control also receives three calls:

1. draft;
2. generic critique;
3. final answer.

It does not receive the ConsciOS self-model or universe context.

This is essential because comparing one baseline call against three intervention calls alone would confound architecture with inference budget.

## UI checkbox

The browser exposes:

> **Apply recursive self + universe intervention**

Unchecked:
- the battery records the baseline only.

Checked:
- baseline;
- matched three-pass control;
- ConsciOS three-pass intervention.

The same loaded model is used in every condition.

## Interpretation

A positive `Δ functional vs matched control` is stronger evidence for an architecture-specific functional effect than a positive baseline-to-intervention delta alone.

A positive `Δ ECS` additionally includes the reliability of the evidence available in each condition.

Neither delta establishes phenomenal consciousness.
