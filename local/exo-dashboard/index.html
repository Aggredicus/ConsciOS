Browser security is blocking this runtime

For a phone or tablet, the easiest path is to run ConsciOS locally on the same computer as exo and open the LAN URL printed by the launcher. That keeps both pages on ordinary HTTP inside your trusted network.

Run exo with ConsciOS

The hosted GitHub Pages site is static: it can display ConsciOS, but it cannot start a native Python/MLX process or a Docker container on your computer. The repository now includes a local launcher so the address is created for you instead of asking you to invent one.

1 · On your computer
node scripts/run-exo-local.mjs
2 · To use your phone on the same Wi‑Fi
node scripts/run-exo-local.mjs --lan
3 · Open the URL the launcher prints
It contains the correct exo runtime address automatically.

macOS uses exo's MLX backend. Linux uses the currently documented CPU backend. Native Windows is not documented by upstream exo; use WSL2/Linux for this launcher.
