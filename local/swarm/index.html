Security model

transparent
  • QR/link signaling only; no ConsciOS signaling database.
  • WebRTC DTLS encryption plus ConsciOS ECDH/HKDF/AES-256-GCM application encryption.
  • Internet TURN credentials are temporary and fetched from an explicit HTTPS credential endpoint.
  • Private mode requires TURN relay candidates only.
  • Human safety-code comparison detects invitation/answer substitution.
