# v0.8 Shadow Inference Experiment

## Hypothesis

A model can be evaluated against ConsciOS cognitive state before it receives any causal authority. The Observer/Scientist may provide an explicit subset of already-admitted Global Workspace artifacts to a `CognitiveModel`, record the inference, and compare it with the rule-based World Model without inserting the model result into the live cognitive event graph.

## Control design

- deterministic mock model only;
- task limited to `world-state-summary`;
- context contains only current admitted Global Workspace broadcasts;
- every shadow record declares `causalAuthority: none`;
- shadow results live under Observer ownership, not `state.events`;
- Guardian, Executive, and Expression receive no shadow artifact;
- timeout/error cannot interrupt the primary deterministic loop;
- the reserved First Expression Protocol remains unused.

## Interpretation

Agreement measures narrow task agreement with the rule-based World Model. It is not evidence of consciousness, sentience, self-awareness, or subjective experience.
