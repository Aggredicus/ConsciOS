# Inverse Conway matched-control experiment

This laboratory tests the organizational hypothesis rather than assuming it.

A future isolated product requirement is implemented twice from the same starting commit and acceptance criteria:

1. **inverse-conway** — development roles receive scoped context, typed handoffs, declared communication edges, and cognitive ownership boundaries;
2. **conventional** — development roles are organized around ordinary frontend/backend/data/testing responsibilities with shared repository context.

The protocol is preregistered in `protocol.json`. Do not change metric definitions after inspecting condition results without versioning a new protocol.

The scorer reports metric-by-metric paired deltas. It intentionally produces no single overall "winner" score: coupling, defects, context cost, and architectural fidelity are distinct outcomes and should remain inspectable.
