# v1.1 Shadow Autobiographical Recall Experiment

## Hypothesis

Verified autobiographical history can be retrieved and evaluated for relevance before it receives any authority to alter ConsciOS cognition.

## Retrieval model

Memory uses a deterministic, inspectable score composed of:

- token overlap with current admitted Global Workspace content;
- preferred historical event type;
- preferred historical source;
- overlap/agreement with structured signals derivable from current Workspace content;
- recency.

Every selected and rejected record exposes the score components that produced its ranking.

## Causal boundary

Recall results declare:

- `recallAuthority: shadow-only`;
- `actionAuthority: none`;
- `causalAuthority: none`.

The Observer may compare historical World-Model snapshots with the current rule-based World Model and report conflicts. Retrieved memory never enters `state.events`, Global Workspace, World/Self Model, Counterfactual, Guardian, Executive, or Expression.

## Interpretation

Successful retrieval demonstrates functional historical relevance, not phenomenal memory or continuous subjective identity. Historical contradiction is treated as a conflict to inspect, never as authority to override current observation.
