# v0.4 Modular Browser Integration Experiment

## Hypothesis
A browser UI can consume the modular runtime without reimplementing cognitive decisions and without modifying the original single-file v0 reference phenotype.

## Controls

- root `index.html` must retain its original Git blob identity;
- the demo imports `runtime/modular-ui.mjs` only;
- the UI adapter imports `runModularV0()` from the runtime integration boundary;
- no external network, LLM, microphone, camera, geolocation, or actuator access is added;
- the modular parity experiment remains authoritative for cognitive output.

## Interpretation
This experiment validates presentation/integration boundaries. It does not add cognition and it does not provide evidence of consciousness.
