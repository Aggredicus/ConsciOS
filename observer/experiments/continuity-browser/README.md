# v1.0 Browser Continuity Integration Experiment

## Hypothesis

The modular browser can preserve a verified autobiographical history across restart without granting that history causal recall authority over cognition.

## Boundaries

- continuity is opt-in;
- root `index.html` remains the unchanged reference phenotype;
- the continuity controller receives completed runtime events after cognition finishes;
- `runModularV0()` receives no journal or persisted-memory input;
- stored autobiography has `recallAuthority: none`;
- `Reset view` resets only transient display/runtime state and never deletes the journal;
- an existing valid journal produces an explicit restart boundary and a new continuity epoch;
- corrupted persisted history fails closed and is not overwritten automatically;
- no clear/delete storage API exists.

## Interpretation

Cross-restart autobiographical persistence is a functional continuity mechanism. It does not establish uninterrupted phenomenal experience or identity.
