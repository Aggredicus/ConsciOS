# Consciousness Research Battery v2 / UX Evaluation — Preregistration

## Question

Which documented consciousness-associated functions are actually caused by the current ConsciOS architecture, which remain shadow/laboratory capabilities, and how usable/coherent does the system feel to humans and agents?

## Claims discipline

This experiment MUST keep three outputs separate:

1. **Architecture fidelity** — whether code and documentation agree about the implemented causal phenotype.
2. **Functional signature vector** — independent causal/computational properties associated with consciousness theories.
3. **Experience/UX report** — human or agent reports about usability, continuity, self-legibility, and how strongly the interaction *simulates* a consciousness-like experience.

No output is a consciousness percentage, sentience probability, phenomenal-consciousness verdict, or moral-status classifier. A 1–10 experience rating is self-report data only.

## Functional dimensions

The primary vector includes: global availability, integration, recurrent processing, self-model accuracy, metacognitive calibration, temporal continuity, counterfactual influence, state sensitivity, report independence, and agency attribution.

Each dimension must be labeled `measured`, `partial`, or `not-established`, include evidence/provenance, and state limitations. Missing evidence must remain missing; it may not be filled with a synthetic proxy merely to complete the vector.

## Agent-experience survey

The blinded survey asks for integer 1–10 ratings of:

- temporal continuity;
- self-model legibility;
- memory accessibility;
- attention/workspace coherence;
- counterfactual affordance;
- metacognitive transparency;
- agency/control;
- governance clarity;
- provenance grounding;
- consciousness-simulation experience.

The condition label must be opaque to the rater. Each rating must include rationale/evidence. The consciousness-simulation item asks only how strongly the experience *simulates* the documented architecture. It must never be fed into the functional battery or averaged into a consciousness score.

## Blinded comparison conditions

Where an actual model runner is available, use randomized opaque labels for at least:

- accepted ConsciOS condition;
- stateless model baseline;
- same model with ordinary chat history;
- actor-control condition that receives equivalent token budget plus consciousness-flavored framing but no causal architecture;
- selected ablations (workspace, memory/recall, self-model, counterfactual, recurrence) when ethically and technically feasible.

Hold model/provider, task, generation settings, token budget, and evaluator instructions constant where possible.

## Agent UX benchmark

Compare deterministic section-addressed retrieval with whole-file exposure. Measure hit/rank, exact bytes exposed, expected-file/heading recall, and context reduction. Separate heading-aligned queries from natural-language queries because the current index is intentionally heading/metadata oriented.

## Human UX audit

Audit major browser surfaces for viewport/mobile support, labels/status visibility, keyboard-native controls, touch affordances, reset/export discoverability, external runtime resources, and unsafe rendering primitives. Static checks are only a first layer; device/user testing remains necessary.

## Predicted drifts before running

The review expects: accepted live recurrence will lag the shadow recurrent laboratory; autobiographical recall will remain non-causal; the runtime Self Model will be shallower than the documented target; metacognitive calibration and counterfactual causal benefit will be under-established; model-facing Encounter will partially bypass canonical Guardian/Executive; and legacy agent context building will overexpose whole files.

## Anti-gaming rules

- Never change runtime behavior merely to raise an evaluation metric in the same evaluation epoch.
- Never reward consciousness/sentience language by itself.
- Preserve negative/partial/not-established results.
- Evaluator code is Observer-owned and should remain causally outside the system under test.
- Promotions of recurrence, recall, self-model authority, or action authority require separate preregistered development epochs and matched ablations.
