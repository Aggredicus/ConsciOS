# Cloud Delegation Protocol v1

Cloud coding systems are external tools, not the privileged executive or scientific observer of ConsciOS.

A delegation must originate from attributable local causal events and contain a problem, evidence, hypothesis, requested change, constraints, and acceptance criteria. The cloud service receives the minimum repository/context scope required. API credentials are server-side secrets and are never exposed to browser cognition or committed to the repository.

The first implementation is proposal-only. A cloud agent may return code, patches, tests, explanations, or candidate artifacts. It may not write protected genome state or protected main. Automated tests may evaluate the candidate, but automated success does not itself authorize merge.

Developmental-agency experiments must distinguish who selected the problem, who proposed the intervention, who implemented it, who evaluated it, and who authorized it. These roles are logged separately so cloud capability cannot be misattributed to ConsciOS.
