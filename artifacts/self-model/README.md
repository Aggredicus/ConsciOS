# Self-model artifacts

This directory is the persistent, reviewable output surface for the ConsciOS Self-Model Memory Fabric (issue #91) and Self-Model Studio v0.2 (issue #93).

`current/` is generated by:

```bash
node scripts/self-model-memory.mjs build --out artifacts/self-model/current
```

The v0.2 validated projection can then be generated and verified with:

```bash
node scripts/self-model-graph-v2.mjs verify artifacts/self-model/current
node scripts/self-model-graph-v2.mjs normalize artifacts/self-model/current --out artifacts/self-model/current/ontology/current.v2.json
```

Generated content is intentionally excluded from subsequent self-model indexing to prevent observer recursion. Commit generated snapshots only when they correspond to a meaningful checkpoint or architectural event; do not create an automatic commit loop on every generated file change.

The system remains shadow/advisory unless a later governed experiment explicitly promotes a causal use. See `development/SELF_MODEL_MEMORY_FABRIC.md` and `development/SELF_MODEL_STUDIO.md` for retrieval rules, graph invariants, discrepancy handling, and governance boundaries.
