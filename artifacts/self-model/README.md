# Self-model artifacts

This directory is the persistent, reviewable output surface for the ConsciOS Self-Model Memory Fabric (issue #91).

`current/` is generated by:

```bash
node scripts/self-model-memory.mjs build --out artifacts/self-model/current
```

Generated content is intentionally excluded from subsequent self-model indexing to prevent observer recursion. Commit generated snapshots only when they correspond to a meaningful checkpoint or architectural event; do not create an automatic commit loop on every generated file change.

The first implementation is shadow-only. See `development/SELF_MODEL_MEMORY_FABRIC.md` for retrieval rules, snapshot triggers, and governance boundaries.
