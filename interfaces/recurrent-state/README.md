# Recurrent State Boundary — v1.4

The recurrent-state artifact is a deliberately small working-state interface between adjacent cognitive cycles in the isolated recurrent laboratory.

It is **not** autobiographical memory and does not contain the prior cycle's full event graph.

Allowed fields:

- schema version;
- prior cycle ID;
- bounded World Model summary;
- bounded Self Model summary;
- explicit prediction summary and confidence;
- previous Executive action ID;
- previous homeostatic status;
- one causal anchor event ID linking the prior cycle to the next recurrent-context event.

The receiving cycle may use only these declared fields. Persistent autobiography, hidden model state, raw chat history, and arbitrary repository context are not part of this interface.

This boundary exists to test temporal recurrence as an inspectable causal mechanism, not to claim continuous subjective experience.
